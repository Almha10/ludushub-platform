# 🎮 LudusHub Platform
🌍 **Live Demo:** https://ludushub-platform.vercel.app
A modern gaming community platform designed to connect players, clubs, and interactive spaces in one place.

---

## 🚀 Overview
LudusHub is a web-based platform that enables gamers to discover clubs, join communities, and engage in shared spaces with a seamless and interactive experience.

---

## ✨ Key Features
- 👤 Player profiles and roles  
- 🏢 Club creation and management  
- 📩 Join request system (accept/reject)  
- 🌐 Community interaction spaces  
- 🎮 Games discovery section  
- 🌍 Multi-language support (Arabic / English)  
- 📱 Responsive modern UI  

---

## 🛠 Tech Stack
- Next.js  
- React  
- JavaScript  
- CSS Modules  
- Supabase
